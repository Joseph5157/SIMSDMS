## Wrapper adoption interpretation

- **Confirmed:** wrapper creation and wrapper adoption are separate outcomes. Spec 025 deliberately began with one representative screen for AppButton, AppField, MobileList, and ResponsiveDataView.
- **Confirmed:** later handoff conventions retained direct page-level Mantine Select filters, Mantine success buttons, and raw ResponsiveSheet footer controls.
- **Inference:** the high direct/native counts are therefore a combination of pre-wrapper historical code, deliberately retained context-specific controls, and incomplete general rollout—not evidence that all bypasses have the same cause.
- **Confirmed:** some wrappers add material behavior (AppSelect, ResponsiveSheet, FormModal, ConfirmDialog); others currently add little beyond naming/defaults (AppTextInput) or duplicate a global guarantee (AppButton’s 44 px minimum for Mantine buttons).
- **Unresolved:** whether wrapper uniformity is worth the API limits and migration cost is reserved for Spec 031.
